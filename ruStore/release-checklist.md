# AZURA Gallery — чек-лист RuStore

## Перед загрузкой
- [ ] Собрать Release APK или AAB и подписать постоянным собственным сертификатом.
- [ ] Сохранить keystore и пароли в безопасном месте вне репозитория; сделать резервную копию.
- [ ] Сохранить package ID `com.azura.gallery` и использовать тот же ключ подписи для будущих обновлений.
- [ ] Проверить, что `versionCode` выше предыдущей загруженной версии.
- [ ] Проверить APK/AAB на реальных устройствах и актуальных версиях Android.
- [ ] Проверить разрешения: полный доступ, ограниченный доступ и отказ пользователя.
- [ ] Проверить запуск, прокрутку большой библиотеки, фото, видео, редактор и экспорт копии, альбомы, избранное, корзину, поиск и умные подборки.
- [ ] Проверить отсутствие `INTERNET` permission, ненужных SDK и трекеров.
- [ ] Проверить все внешние ссылки Telegram, GitHub и MAX.

## Материалы карточки
- [ ] Подготовить реальные скриншоты финальной версии приложения (не рекламные макеты); RuStore требует скриншоты мобильной версии.
- [ ] Подготовить иконку без прозрачных незаполненных краёв.
- [ ] Заполнить название, краткое описание (до 80 символов), подробное описание (до 4000 символов), категорию и теги.
- [ ] Заполнить контакты разработчика, возрастной рейтинг и сведения о правах на код/графику.
- [ ] Опубликовать окончательную политику конфиденциальности по общедоступной HTTPS-ссылке и добавить её в карточку, если этого требует состав обработки данных.
- [ ] Проверить подпись APK через `apksigner verify --verbose`.
- [ ] Убедиться, что обновления будут подписаны тем же ключом.

CI проверяет компиляцию, unit-тесты и метаданные APK, но не может гарантировать одобрение модерацией и не заменяет ручное тестирование на реальных телефонах.
